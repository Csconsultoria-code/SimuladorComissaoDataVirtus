# Simulador de Comissão — Data Virtus

Simulador de remuneração variável desenvolvido pela CS Consultoria para a Data Virtus.
Compara três modelos de cálculo do variável do vendedor:

1. **Bônus por metas** — até um valor máximo, conforme atingimento das metas de vendas e faturamento (com gatilho mínimo).
2. **Comissão fixa** — percentual fixo sobre todo o faturamento do mês, sem teto.
3. **Comissão por faixa de faturamento** — percentual da faixa atingida aplicado sobre todo o faturamento, sem teto.

Abra `index.html` no navegador ou acesse pela página do GitHub Pages.
